# 验证说明

## macOS

`bash macos/test.sh` 运行合成进程与自建无害模拟进程测试。覆盖桌面与辅助进程路径、内置/独立 Claude Code、Node/Bun 入口、npm 符号链接、常见误匹配排除、PID/用户/出生时间身份保护、后代追踪及 `exec` 后身份保持。

真实进程测试仅向测试自行创建并记录身份的子进程发送信号。`CloseIntegrationTests.m` 在编译期把进程枚举替换成固定的自建进程白名单，默认为空且没有真实系统枚举回退；非零信号另有 PID/用户/出生时间白名单校验，桌面退出 API 也替换为空实现。在这些隔离条件下执行完整关闭流程，验证先子后父的 TERM 以及忽略 TERM 后的 KILL 路径，不会关闭用户实际 Claude。CI 分别在 Apple Silicon 和 Intel 主机运行，并验证 Universal 应用的两个架构。

`./macos/build/ClaudeControl --status` 可在本机做只读冒烟检查。状态中的权限/覆盖警告也应检查，不能只看数量。

进程在扫描期间退出或执行新程序时，可能出现一次性的读取覆盖警告。此时应重新检查，不能为了显示零进程而静默忽略读取失败。

1.0.2 补充父 PID 复用时的子/父创建时间约束、未知 Node/Bun 选项的歧义警告、被改写标题的入口线索，以及保护链读取失败与已捕获任务暂不可读同时发生时的回归。详见 [复查记录](REVIEW.md)。

## Windows

核心测试可跨平台运行；Windows 本机测试额外验证进程快照、用户/会话边界、真实进程身份复核与自建模拟进程结束。构建流程还验证自包含发布包的只读检查命令，避免只测试源码而漏掉打包错误。

CI 使用 Windows x64、Windows ARM64 原生主机。编译器或测试失败会阻止标签发布。

1.0.2 另覆盖 Node `--run=` 与尾随脚本参数的误匹配、常见安全选项、Bun 显式文件入口、父 PID 被复用时保护链的失败处理，以及已捕获子任务暂时不可读后恢复的情形。

## 未被这些测试证明的事项

- 每一种 Claude 历史/未来版本、安装方式、定制启动器或权限组合都被识别。
- 终止用户真实 Claude 时一定没有未完成工作或数据损失。
- 网络不泄漏真实 IP、代理生效或 Claude 已经发送的数据被撤回。
- 扫描间隙中的短命进程、无法追溯的孤立进程、检查后自动重启都不会出现。
- macOS 公证、Windows 商业签名或每种系统安全产品均已通过。

## 发布过程

运行 `.github/workflows/build.yml`。普通推送提供工作流构件，`v*` 标签在所有构建和测试成功后由发布作业创建 Release，并给每个 ZIP 生成 SHA-256 校验值。Release 中的包与同一标签的源码相对应。
